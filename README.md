# Java Backend Journey

Repository to learn Java step by step with a backend focus.

This repository documents my journey from Java fundamentals to building real backend systems using Spring Boot.

## Goals
- Learn modern Java
- Build strong OOP foundations
- Move into Spring Boot backend development
- Create real backend projects with databases and APIs

## Structure
- `java-basics/`: core Java exercises
- `spring-boot/`: backend projects with Spring Boot
- `docs/`: notes and learning references
- `exercises/`: small coding challenges

## Learning Roadmap

### Phase 1 – Java Fundamentals
- Hello World
- Input / Output
- Control Flow
- Loops
- Arrays
- Collections
- OOP

### Phase 2 – Intermediate Java
- Streams
- File handling
- Exceptions
- Multithreading

### Phase 3 – Backend
- Spring Boot
- REST APIs
- Databases (PostgreSQL)
- Authentication (JWT)
- Docker
